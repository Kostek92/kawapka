# Prototype (visual reference only)

`screens/*.png` are the original mockups and `code/*.html` their HTML source.
They are kept unchanged as a source for layout, styling, and flow, and are not
kept in sync with the app:

- Labels and copy may be outdated (e.g. “Discover” and “Favourites” where the
  app uses catalogue / personal collection wording).
- The Favourites screen shown here is not part of the first release: favourite
  status and the favourites view were skipped.

When the prototype and [`docs/PRODUCT_SPEC.md`](../PRODUCT_SPEC.md) disagree,
the spec wins.
